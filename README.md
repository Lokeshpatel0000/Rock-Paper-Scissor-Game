# Rock-Paper-Scissor-Game
This is my first repository of rock paper scissor game

Rock Paper Scissors Game
A simple browser-based Rock Paper Scissors game built using HTML, CSS, and JavaScript.

Features
Interactive UI with hover effects.Keeps track of the score for both the User and the Computer.
Displays dynamic status messages based on game results (Win, Lose, or Draw).

Technologies Used
HTML5 for structure.CSS3 for styling and layout.JavaScript (ES6) for game logic and DOM manipulation.

How to Run
Clone or download this repository to your local machine.
Make sure you have three image files (rock.jpeg, paper.jpeg, and scissor.jpeg) in your project folder.
Open index.html in any web browser to play the game.
